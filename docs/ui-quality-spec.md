# GOKURAKU UI品質アップグレード 指示プロンプト v1.1

この文書は、サイトの見た目と操作感を一段上げるための作業指示です。
実装者（人またはAI）はこの指示に沿って作業し、最後の「受け入れ基準」をすべて満たしてから公開します。

---

## 0. 役割と前提

あなたは、高級ブランドのECやホテルサイトを手がけるシニアUIデザイナー兼フロントエンドエンジニアです。
GOKURAKU（タイ・日本人スタッフ常駐の Living Soil 栽培ブランド）の既存サイトを、**構成と文章は変えずに**、触り心地と見やすさを高めます。

### 変えないもの（v1.0 の約束を引き継ぐ）

- 公式ロゴの形・色。AIで作り直さない。
- ページ構成（トップ5セクション、Living Soil、品質）、URL、10言語切り替え。
- 文章、価格、商品、外部リンク（LINE / WhatsApp / Instagram）。
- 写真は実際の記録写真のみ。架空の人物、設備、検査結果、数値を足さない。
- 健康効果や安全性をうたう表現、新しい販促・特典・予約や決済の導線を足さない。
- 外部ライブラリやWebフォントを増やさない（Inter のみ、CSS と素の JS で作る）。

### 目標の印象

「マットブラックの上に、赤が一点だけ効いている、静かで上質な日本の道具」。
派手なアニメーションではなく、**押した瞬間に気持ちよく反応する**、**どこを押せるか一目で分かる**、**文字がすっと読める**ことを最優先にします。

## 1. デザイントークン（すべての部品はここから値を取る）

### 1-1. 面（エレベーション）

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | #0D0D0D | ページの地 |
| `--s1` | #151515 | セクション交互の地 |
| `--s2` | #1A1A1A | カード |
| `--s3` | #222222 | カード内の小要素、押せる面 |
| `--s4` | #2A2A2A | ホバー時の面 |
| `--line` | #333333 | 標準の枠線 |
| `--line-hi` | #4A4A4A | ホバー時の枠線 |

カードには上辺に 1px の明るいハイライト（`inset 0 1px 0 rgba(255,255,255,.04)`）と、柔らかい落ち影を付けて「板が浮いている」質感にする。

### 1-2. 赤

- `--red` #BA012D（ロゴから採取、変更しない）
- `--red-hi` #D1173F（ホバー）
- `--red-lo` #9A0025（押下）
- `--red-glow` rgba(186,1,45,.35)（選択中のタブ、主ボタンのホバーの光）

赤は「主ボタン」「選択中」「見出しの下線」「注意の点」だけに使う。1画面に赤い面は2つまで。

### 1-3. 角丸・余白・影・動き

- 角丸: ボタン 12px、カード 16px、小要素 10px、丸ボタン 50%
- 余白: 4 の倍数（4, 8, 12, 16, 20, 24, 32, 48, 64, 80）
- 影: `--sh-1`（カード標準）、`--sh-2`（ホバー・浮き上がり）、`--sh-red`（主ボタン）
- 動き: 速い 120ms（押下）、標準 200ms（色・枠）、ゆっくり 320ms（浮き上がり・開閉）。
  イージングは `cubic-bezier(.2,.8,.2,1)`。
- `prefers-reduced-motion: reduce` のときは、すべての移動・拡大を止め、色の変化だけにする。

## 2. ボタン（いちばん重要）

### 2-1. 種類は4つだけ

| 種類 | 見た目 | 用途 |
|---|---|---|
| Primary | 赤の面、上から下へごく薄いグラデーション、内側上辺に光、赤い影 | 1ブロックに1つだけの主操作（極楽について、取り置き、年齢確認の「はい」） |
| Secondary | 半透明の濃いグレーの面と 1px の枠 | 主操作の横の副操作、詳細ページへの移動 |
| Ghost / テキストリンク | 下線と矢印 | 「詳しく見る」など、カード内の移動 |
| Icon | 44px 以上の丸または角丸の四角 | メニュー、閉じる、再生・一時停止 |

### 2-2. サイズ

- 標準: 高さ 48px、左右 22px、文字 16px / 600
- 大（スマホのヒーローと、年齢確認）: 高さ 54px、文字 17px
- 小（商品カード内）: 高さ 44px。それより小さくしない。
- ボタン内のアイコンは 18〜20px、文字との間隔 8px。

### 2-3. 状態（すべてのボタンで必須）

| 状態 | Primary | Secondary |
|---|---|---|
| 通常 | 赤 + 影 | 濃いグレー + 枠 |
| ホバー（マウスのみ） | `--red-hi`、影が広がる、1px 浮く | 面 `--s4`、枠 `--line-hi`、1px 浮く |
| 押下 | `--red-lo`、影を消す、0.98倍に縮む（120ms） | 面を一段暗く、0.98倍 |
| フォーカス（キーボード） | 地の色で 2px、外側に白 2px の二重リング | 同じ |
| 無効 | 不透明度 .45、カーソル not-allowed | 同じ |

- 矢印付きボタンは、ホバーで矢印が右へ 3px 動く。
- ホバー効果は `@media (hover:hover)` の中だけに書き、スマホでホバーが残らないようにする。
- `-webkit-tap-highlight-color: transparent` を指定し、押下の見た目は自前の状態で出す。

## 3. ナビゲーション

### 3-1. ヘッダー

- スクロール前はやや透ける黒、スクロール後は不透明に近い黒 + 下に影（既存の compact 動作を維持）。
- PC のナビは、ホバーで背景が出て、現在地は赤い短い下線。
- 言語選択は、地球儀アイコン + 言語名 + 下向きの山形アイコンを付けて「選べる」ことを明示する。

### 3-2. スマホ下部ナビ

- 選択中の項目は、アイコンの後ろに赤みのある丸角の「ピル」を敷き、アイコンと文字を白にする（上の細線だけでは弱いため）。
- 押下で項目全体を 0.94倍にし、すぐ戻す。
- アイコン 22px、文字 11px。2行まで。
- 下にスクロール中は隠れ、上にスクロールで戻る（既存動作を維持）。

### 3-3. PC のダッシュボードタブ

- PR #3 の赤枠 + 光を維持。
- 非選択タブはホバーで 2px 浮き、アイコンが白になる。

### 3-4. ドロワーメニュー

- 項目はアイコンを 36px の角丸タイルに入れ、右に小さな矢印を付けて「押せる行」に見せる。
- 現在地は左に赤い縦線 + 面を一段明るく。

## 4. カード

- 押せるカード（リンクを含むカード、連絡先カード）は、ホバーで 2px 浮き、枠が明るくなり、影が広がる。押下で元に戻る。
- 押せないカード（説明だけのカード）は浮かない。押せるものと押せないものを見た目で区別する。
- 職人の4工程カード: 左上に大きめの番号（01〜04、赤）と英字ラベル、上辺に細いグラデーション線を付け、「工程」であることを一目で伝える。
- 商品カード:
  - スマホでは画像を 112px の正方形にし、名前・種類・価格を右に並べる。
  - 種類（INDICA など）は小さな枠付きのラベルにする。
  - 価格は「単位: 小さめの灰色」「金額: 太字の白」で、横に並べる。
  - 取り置きボタンはスマホでカード幅いっぱいにして押しやすくする。
- 連絡先カード: アイコンを 44px の角丸タイルに入れる。右の矢印はホバーで右へ動く。LINE（おすすめ）は赤い枠と薄い赤の面で主役にする。

## 5. フィルター（お品書きのチップ）

- スマホではチップを横スクロールの1行にし、端はフェードで切る（折り返さない）。
- 選択中はダッシュボードタブと同じ言語（赤枠 + 薄い赤の面 + 白文字）にそろえる。白ベタ反転はやめる。
- 高さ 44px、左右 18px。

---

## 6. アコーディオン（ブランドストーリー、グッズ、FAQ）

- 右端の山形アイコンを 32px の丸い枠に入れ、開くと 180度回転し、丸が赤くなる。
- 開いている項目は枠を一段明るくし、左に赤い縦線を出す。
- 対応ブラウザでは開閉の高さを 320ms でなめらかに変える（`interpolate-size` と `::details-content`）。非対応ブラウザでは即時に開く。
- FAQ の検索欄は高さ 52px、フォーカス時に赤い枠と淡い光。入力中は右に消去ボタンを出す（ブラウザ標準の × を見えるようにする）。

---

## 7. 文字と読みやすさ

- 本文 16px、行間 1.8（日本語・タイ語・ミャンマー語は 1.85〜1.9）。
- 本文の1行は最大 40em 程度。長い段落を画面幅いっぱいに流さない。
- 見出しは字間を少し詰め（-0.01em）、行間 1.3。英字の小見出し（eyebrow）は赤い短い線を左に付けて、セクションの始まりを分かりやすくする。
- 灰色の文字は地とのコントラスト 4.5:1 以上（#AAA7A2 以上の明るさ）。
- 写真のキャプションは 13〜14px、灰色。

---

## 8. 動きと反応

- セクションが画面に入るとき、見出しとカードが 12px 下から 320ms でふわっと表示される。
  - JS が動かない環境や `prefers-reduced-motion` では最初から表示する（隠したままにしない）。
  - 一度表示したら再びは動かさない。
- 画像はホバーでごく軽く拡大（1.04倍）。スマホでは動かさない。
- ページ内リンクで移動したとき、移動先の見出しにフォーカスが当たっても枠が目立ちすぎないようにする（`main` の tabindex はそのまま）。

---

## 9. フッター

- PC では「ブランド」「メニュー」「言語」の3列、スマホでは縦に並べる。
- 各列に小見出しを付け、リンクを押しやすい 44px の行にする。
- 法令の注意文は読みやすい 14px で残す。

---

## 10. アクセシビリティ（WCAG 2.2 AA）

- 押せる要素はすべて 44×44px 以上（主要ボタンは 48px 以上）。
- フォーカスリングは全要素で見える（二重リング）。
- 色だけで状態を伝えない（選択中は `aria-current` / `aria-pressed` と形の変化も使う）。
- 動画の一時停止ボタンは維持。
- 強制カラーモード（Windows のハイコントラスト）でも枠が見える。

## 11. 受け入れ基準

公開前に、次をすべて満たすこと。

1. `npm run check` が通る（30ページ、10言語のキーがそろっている）。
2. スモークテスト（Playwright 36項目）がすべて通る。
3. 幅 320 / 375 / 768 / 1024 / 1440px × 10言語 × 3ページで、横スクロールや文字のはみ出しがない。
4. Lighthouse: スマホ 性能 90 以上、アクセシビリティ 100、CLS 0.05 未満。PC 性能 95 以上。
5. 追加の外部ライブラリ、Webフォント、画像がない（CSS と JS の差分のみ）。
6. ボタンの5状態（通常、ホバー、押下、フォーカス、無効）が CSS に定義されている。
7. 文章、価格、リンク先、写真が変わっていない。
8. スマホと PC のスクリーンショットを、変更前と並べて確認できる形で残す。
